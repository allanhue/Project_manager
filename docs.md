# PulseForge

## System overview

PulseForge is a shared workspace for organizations to plan projects, coordinate day-to-day work, and keep decisions and progress visible. It brings project delivery, team collaboration, approvals, time tracking, and reporting into one place so teams can follow work from planning through completion.

The workspace is organized around each organization. Team members can work with shared projects and tasks, record time, raise issues, and discuss topics with colleagues. Administrators have additional tools for managing their organization and keeping its workspace configured.

## What teams can do

### Plan and deliver projects

- Create and maintain projects with status, dates, duration, team size, project codes, and assigned team members.
- Break project work into tasks, organize tasks by phase, and track priority, status, and subtasks.
- See project and task progress from the dashboard, calendar, and reporting views.

### Coordinate work and resolve blockers

- Record work against a project or task with timesheets, hours, dates, notes, and billable status.
- Raise issues with a description, severity, optional project link, and tags.
- Add comments to an issue to keep follow-up and resolution discussion with the issue.
- Use the forum to share questions, updates, and ideas; tag posts and keep replies in a thread attached to each post.
- Share code snippets and technical notes with the Dev Share workspace.

### Manage requests and decisions

- Submit approval requests for project-related work and hours.
- Review requests and record approval decisions, with the available workflow guided by workspace settings.
- Use the calendar to follow project and task dates and view scheduled system updates.

### Understand progress

- Review a dashboard summary of project and task activity.
- Use analytics to see project status and delivery trends.
- Build reports across projects, tasks, and issues, with the option to focus on a project.

## Workspace administration

Organization administrators can manage organization users, projects, workspace preferences, and profile details. Settings include options for reminders, notifications, approvals, privacy, and data retention. Available controls depend on the signed-in role.

System administrators have a separate administration experience for platform support, configuration, and system-wide activity. Organization work and system administration are presented as distinct workspaces.

## Access and collaboration

PulseForge provides sign-in and organization-scoped workspaces. Work is shared with the relevant organization, while platform administration is reserved for system administrators. Users can update their profile and personal preferences from their workspace.
